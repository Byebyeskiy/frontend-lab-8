# Лабораторна робота №8 — JavaScript Basics

Проєкт містить ES-модулі, дані прикладів, браузерний інтерфейс та тести Node.js.

**Репозиторій:** https://github.com/Byebyeskiy/frontend-lab-8

## Запуск
1. Відкрийте папку проєкту у Visual Studio Code.
2. Переконайтеся, що встановлено Node.js 20+.
3. Запустіть `node --test` у терміналі.
4. Запустіть `npx serve .` або Live Server / Live Preview та відкрийте локальну адресу.
5. **Не відкривайте `index.html` через `file://`**: браузер обмежує завантаження ES-модулів і `fetch` з файлового протоколу.

## Структура
- `src/` — п'ять модулів із функціями завдань C1–C5.
- `test/` — локальні перевірки через `node:test`.
- `data/` — демонстраційні дані серіалів.
- `index.html`, `main.js` — інтерфейс і точка входу.
- `REPORT.md` — пояснення й результати дослідів.

## Перевірка
Локально 21.10.2026 команда `node --test` завершилась успішно: 5 тестів пройдено, 0 помилок.

**Примітка:** Оригінальний архів `js-basics-starter.zip` та його точні тести не були надані. Ця самостійна реалізація відтворює описані завдання, але назви полів/формат результату можуть відрізнятися від оригінального ТЗ. Демонстраційний JSON містить 5 прикладів, а не оригінальні 30 записів TVmaze. Публікацію на GitHub Pages або Vercel ще треба налаштувати.
